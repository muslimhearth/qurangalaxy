# G7: Latin spelling search

## Done
- `src/search/spelling.ts`: `spellingMatcher` finds roots from Latin spellings ("noor", "rahmaan", "3ilm", "ar-rahman"). Reason kind `latin`, text = matched lemma (with diacritics) or root letters.
- Registered in `src/search/matchers.ts`.
- Unit tests `src/search/spelling.test.ts`: 63 real-galaxy cases (top result and expected lemma), fixture cases, root-letter search still works, speed check.
- Browser test `e2e/spelling.spec.ts`: "noor" → نور first, "3ilm" → علم first, Enter on "rahmaan" opens رحم.

## Decisions
- Pattern, not candidates: the query becomes tokens. Each token lists the Arabic letters it can stand for, with a cost (0 = normal). A small dynamic program finds the cheapest spelling of each lemma and root.
- Ambiguous letters cost nothing (s = س/ص, h = ه/ح/ة, t = ت/ط/ة, d = د/ض, z = ز/ظ, k = ك/ق). Root word count breaks ties.
- Short vowels are optional. Long vowels (aa, ee, oo) cost 1 when missing. A word-initial vowel may be ا, ع or ا+ي/و ("iman" = إيمان). A final "a" may be ة or ى.
- Vowel quality: the query vowels are compared with the lemma's diacritics (edit distance). So "zikr" gives ذِكْر, not ذَكَرَ. Root letters have no vowels, so lemmas win ties.
- Search form: ؤ → و, ئ → ي, اا → ا on top of `normalizeArabic` ("mumin", "quran").
- Scores: tier (1 / 0.8 / 0.6) minus at most 0.15 for cost, so tiers never overlap. Prefix and inner matches need 3+ query letters.
- Index: one entry list per roots array (WeakMap), plus a letter bit set per entry to skip most forms fast. About 3 ms per query in jsdom.

## Open issues
- Proper names (Musa, Ibrahim, Isa) are not lemmas in the data, so they do not match.
- Ain inside a word without a mark ("dua", "sharia") costs 1, so a root without ain can win ("dua" → ضوأ first, دعو second). Users can type "du3a" or "du'a".
- Short "a" fits both short and long readings: "hajj" shows حاجّ as reason, "halal" works by a tiny cost for skipped vowels.
- English words also run through this matcher and can give weak hits (e.g. "mercy" → مُرْسَى at 0.975). An English matcher with exact 1.0 still ranks first.
