# G10: Corpus word-by-word English glosses (local evaluation)

## Licence status
The corpus team has not yet allowed reuse of the glosses. All scraped data is **local evaluation only**:
- Raw pages: `data/raw/corpus-wbw/pages/*.html` (word table only, 2,662 files, 40 MB, gitignored).
- Download log: `data/raw/corpus-wbw/log.txt`.
- Aggregate: `data/derived/corpus-glosses.json` (1.5 MB) and `data/derived/corpus-wbw-validation.json` (gitignored; `data/derived/` added to `.gitignore`).
- Nothing goes to `public/data/`. The data build does not read these files.
- Committed: code, tests, two small HTML excerpts as test fixtures, and the spot-check table below.

## Done
- `pnpm corpus:wbw` (`scripts/corpus-wbw.ts`): scraper.
  - Checks `https://corpus.quran.com/robots.txt` first. The site has no robots file (302 redirect to `/`), so no rules apply. A `Disallow` that matches `/wordbyword.jsp` stops the run.
  - Strictly serial, 1.1 s between request starts, User-Agent `root-gloss-builder/1.0`, exponential backoff (5, 10, 20, 40 s), stops after 3 verses fail in a row.
  - One page shows several whole verses (about 20 words). The scraper asks for the first verse not yet covered, so the full Quran took 2,662 requests (about 50 minutes), not 6,236.
  - Resumable: on start it parses the cached pages and fetches only uncovered verses.
- `pnpm corpus:glosses` (`scripts/corpus-glosses.ts`): validates word counts, aggregates, prints coverage. A comma-separated root list as argument prints a spot-check table.
- Pure modules in `scripts/lib/corpus-wbw/`, each with tests (no network in tests):
  - `parse.ts`: page HTML → `{ location, translit, gloss }` per word. `extractTable` keeps only the word table for the cache.
  - `morph-index.ts`: morphology file → verse order, word counts, main lemma and root per word, plus flags (proper noun, verb, preposition prefix, pronoun suffix).
  - `coverage.ts`: complete verses per page, next uncovered verse, page URL.
  - `polite-fetch.ts`: throttled fetch with backoff (fake clock in tests), robots.txt check.
  - `normalize.ts`: raw gloss → head form.
  - `aggregate.ts`: merge pages, validate word counts, top glosses per lemma and per root.
  - `load.ts`: integration hook (below).

## Normalization (head form)
Each gloss is matched to the word's main segment: the root segment, else the first non-prefix segment with a `LEM:`. Steps:
1. Drop standalone helper words in `( )` and `[ ]`: `(there is) no` → `no`. Join a glued part: `what(ever)` → `whatever`. A gloss that is only a helper word keeps it: `(is)` → `is`.
2. Trim quotes and punctuation.
3. Drop leading `o`, `and`, `so`, `then`, `but`, `or`, `the`, `a`, `an` and possessives (`his`, `their`, ...).
4. Drop a leading preposition only if the word has a preposition prefix (bi, li, ka). Drop a leading subject pronoun only for verbs (`they believe` → `believe`). Drop a trailing object pronoun only if the word has a pronoun suffix (`overtakes Him` → `overtakes`).
5. Lowercase, except proper nouns (`PN`) and words that start with `Allah`.
6. Never strip a gloss to nothing. Count identical forms. Keep the top 8 per lemma and per root.

## Quality issues
- **Root lists mix unrelated lemmas.** The most frequent lemma wins the root: نور → "fire" (نار, 145) before "light" (نُور, 41). سمو mixes "heavens" and "name". علم shows "worlds" (عالَمِين). ظلم mixes "wrongdoers" and "darkness". Prefer the lemma list. Use root glosses only as a fallback, or take the top gloss of each top lemma.
- **Verb forms are not merged.** قالَ gives "said", "say", "will say", "says". A head form needs one base form (e.g. "say"). Possible fix: prefer the gloss of the perfect 3MS form, or strip auxiliaries (will, was, have).
- **Contextual phrases.** Glosses translate the word in its verse: "Allah lets go astray", "he can cause the wind to become still", "surely we will attack him by night", "is there any god". These need a length cap or a filter.
- **Idioms and pronoun compounds.** يد shows "before" (from بَيْنَ أَيْدِي) and "him", "them". نَفْس shows "themselves", "yourselves".
- **Transliterated terms.** "zakah", "bahirah", "al-masjid", "al-masjid al-haraam". Clear for experts, opaque for others.
- **Leftover prefix words.** A few remain: "by my lord", "concerning your lord", "while the earth".
- **Near-duplicates.** "most merciful" / "most-merciful", "all praise" / "all praises", "all-knower" / "all-knowing".
- **Homograph lemmas.** 5 lemma strings occur under two roots (e.g. جَواب, عَصا). The lemma map keys on the lemma string only, so their glosses merge. A key `root|lemma` would be safer if this matters.
- Overall: frequent concrete nouns are excellent (sun, moon, water, earth, tree, honey, milk, fig). Most top lemma glosses are usable as they are.

## Integration hook
`scripts/lib/corpus-wbw/load.ts`:
- `loadCorpusGlosses(path = 'data/derived/corpus-glosses.json', limit = Infinity)` returns `{ lemmas: Map<lemmaAr, string[]>, roots: Map<rootAr, string[]> }`, or `undefined` when the file is missing.
- `toGlossMaps(file, limit)`: the pure conversion.
- Keys are the corpus `LEM:` and `ROOT:` strings, the same strings that `scripts/lib/morphology.ts` uses.
- Not wired into `scripts/build-data.ts`. Plug it in as the top gloss source once permission arrives.

## How to rerun
1. `pnpm corpus:wbw` (skips cached verses; a fresh full run takes about 50 minutes).
2. `pnpm corpus:glosses 'نور,صبر,…'` (the optional root list prints the spot-check table).
